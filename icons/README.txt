ICON REQUIREMENTS FOR CAUGHTIN4KNJIT
=====================================

This extension requires three icon files in PNG format:

1. icon16.png  - 16x16 pixels (for extension toolbar)
2. icon48.png  - 48x48 pixels (for extension management page)
3. icon128.png - 128x128 pixels (for Chrome Web Store)

PLACEHOLDER ICONS:
Currently using placeholder files. For production, replace these with:

- A shield or lock icon representing security
- Purple/blue gradient color scheme matching the extension theme
- Professional, modern design
- Transparent background (PNG format)

DESIGN SUGGESTIONS:
- Shield with "C4K" or "NJIT" text
- Lock with email envelope
- Warning/alert symbol with protective shield
- Purple gradient (#667eea to #764ba2)

TOOLS TO CREATE ICONS:
- Figma (https://figma.com)
- Canva (https://canva.com)
- Adobe Illustrator
- Inkscape (free)
- GIMP (free)

Or use online icon generators:
- https://favicon.io/
- https://realfavicongenerator.net/
- https://www.iconfinder.com/

INSTALLATION:
Replace the placeholder files in this directory with your actual PNG icons,
keeping the same filenames (icon16.png, icon48.png, icon128.png).
